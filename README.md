# sonrisa-alerts

Take-home task for Sonrisa: an event alert feature (email + Slack, extensible channels, admin view) built from a one-paragraph PM brief using AI agents.

**The process artifacts are the submission; the code is evidence.** Start here:

1. `docs/00-plan.md` — how I scoped the brief and in what order I built it
2. `docs/01-assumptions.md` — what the brief left open and what I decided
3. `docs/03-decision-log.md` — every non-obvious choice, with the alternative rejected
4. `docs/04-ai-review-log.md` — what the AI produced, how I checked it, what I rejected
5. `prompts/` — every prompt sent to the AI, verbatim (`raw.md`) and summarized (`log.md`)

`CLAUDE.md` contains the rules the AI worked under. Setup and run instructions are added once there is something to run.
